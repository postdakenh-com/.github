# PostĐaKênh (postdakenh.com)

**Tạo nội dung một lần. Đăng đa kênh tức thì.**

PostĐaKênh là công cụ đăng và lên lịch bài đa kênh cho người Việt — Facebook, TikTok, YouTube, Instagram, Threads, LinkedIn, Telegram và Zalo OA, Pinterest, và nhiều hơn nữa — có Public API và MCP để AI agent như Claude, ChatGPT tự đăng bài.

*Social media scheduler built for Vietnam: post once to Facebook, TikTok, YouTube, Instagram, Threads, LinkedIn, Telegram and Zalo OA, Pinterest with a public API and MCP for AI agents.*
